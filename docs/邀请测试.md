# 邀请测试发布指南

> 目标：把 app 放到华为 AGC 的「邀请测试」，让指定华为账号安装，不走公开商店、不需要 APP 备案。

---

## 0. 现状

| 项 | 值 |
|---|---|
| 包名 | `com.daomanliu.eas` |
| 版本 | `1.0.0` (versionCode `1000000`) |
| 目标 API | 26.0.0 |
| 当前签名 | debug（`debugKey`），**不能上传 AGC** |
| 联网 | 仅 `ohos.permission.INTERNET` |
| 数据 | 全部本地（preferences），无服务器 |

---

## 1. 注册开发者账号

1. 打开 <https://developer.huawei.com/consumer/cn/>，注册并**实名认证**
   - 个人开发者：身份证实名，免费
   - 企业开发者：营业执照，需付费
2. 个人实名通常 1 个工作日内通过

---

## 2. AGC 创建应用

<https://developer.huawei.com/consumer/cn/service/josp/agc/index.html> → 「我的应用」→ 新建：

| 字段 | 填写 |
|---|---|
| 应用名称 | SWU教务 |
| 应用包名 | `com.daomanliu.eas` |
| 应用分类 | 教育 / 工具 |
| 默认语言 | 简体中文 |
| 终端 | 手机 |

> 包名一旦创建不可改，必须和 `AppScope/app.json5` 里的 `bundleName` 完全一致。

---

## 3. 生成发布证书与 Profile

### 3.1 创建密钥与证书请求

AGC → 「证书、APP ID 和 Profile」→「证书」→ 新建：

1. 选择 **发布证书**（不是调试证书）
2. AGC 会让你上传 `.csr`。本地生成：

```bash
# 在 DevEco 的 Tools 目录或任意 keytool 环境
keytool -genkeypair -alias swuRelease -keyalg EC -keysize 256 \
  -sigalg SHA256withECDSA -dname "C=CN,O=SWU,CN=SWU Eas" \
  -keystore release_SWU.p12 -storetype pkcs12 -validity 9125 -storepass 你的密码
keytool -certreq -alias swuRelease -keystore release_SWU.p12 \
  -file release_SWU.csr -storepass 你的密码
```

3. 上传 `release_SWU.csr`，下载得到的 `release_SWU.cer` 和 `release_SWU.p7b`（profile）

### 3.2 创建 Profile

「Profile」→ 新建 → 类型选 **release**：

- 绑定应用：`com.daomanliu.eas`
- 绑定证书：上一步的发布证书
- release profile **不需要填设备 UDID**（邀请测试通过应用市场安装）

---

## 4. 配置签名

`build-profile.json5` 里已经放好 `release` 配置模板，把四个路径改成你本机的真实文件：

```json5
{
  "name": "release",
  "type": "HarmonyOS",
  "material": {
    "certpath": "…\release_SWU.cer",
    "keyAlias": "swuRelease",
    "keyPassword": "…",
    "profile": "…\release_SWU.p7b",
    "signAlg": "SHA256withECDSA",
    "storeFile": "…\release_SWU.p12",
    "storePassword": "…"
  }
}
```

密码是 DevEco 加密后的形式，最简单的做法是：
**DevEco Studio → File → Project Structure → Signing Configs → 取消勾选 Automatically generate signature → 手动填四项**，IDE 会自动写回加密密码。

然后把 `products[0].signingConfig` 改成 `"release"`。

---

## 5. 构建 release HAP

```
Build → Build Hap(s)/APP(s) → Build Hap(s)
```

产物：
```
entry/build/default/outputs/default/entry-default-signed.hap
```

检查签名是否 release：

```bash
# 解压 HAP 里的 META-INF 看证书
unzip -l entry-default-signed.hap | findstr META-INF
```

---

## 6. AGC 提交邀请测试

「我的应用」→ 你的应用 →「测试与发布」→「邀请测试」：

1. **上传 HAP**
2. 填版本信息
   - 版本号自动读 HAP，需与上次不同
   - 更新说明：一句话即可
3. **应用信息**（首次需要）
   - 应用图标 216×216 PNG
   - 应用截图：至少 2 张，推荐 1080×1920
   - 应用简介：40~80 字
   - 隐私政策 URL（必须有）
4. **测试用户**
   - 添加测试同学的**华为账号**（手机号或邮箱）
   - 单个应用上限通常 1000 人，具体看 AGC 当前政策
5. 提交 → 邀请测试**通常免深度审核**，几小时内生效

---

## 7. 测试用户如何安装

测试用户（已加入白名单、已登录同一华为账号）：

```
华为应用市场 → 我的 → 应用尝鲜 / 邀请测试 → 找到 SWU教务 → 安装
```

或直接用你分享的邀请链接 / 二维码。

---

## 8. 隐私政策（必填，给个可用的最小版本）

需要一个可公开访问的 URL，内容至少包含：

1. 收集哪些信息：**不收集**，账号密码只在校内登录页输入，应用不读取
2. 数据存储：课表/成绩/考试仅保存在本机 preferences
3. 网络请求：仅在用户主动点击「开始同步」时访问 `jw.swu.edu.cn`
4. 权限：仅网络权限
5. 联系方式：开发者邮箱

托管方式：GitHub Pages / Gitee Pages / 语雀公开文档，都能满足。

---

## 9. 已知风险

| 风险 | 说明 | 规避 |
|---|---|---|
| 校名 + 校徽 | 使用「西南大学」名称和校徽，可能被要求提供授权 | 邀请测试范围内一般不会触发公开审核，转为公开上架前必须处理 |
| 教务数据抓取 | 涉及第三方系统 | 说明为「用户本人授权登录、数据仅本地」 |
| 备案 | 公开发布必须有 APP 备案 | 邀请测试不需要，正式上架前补 |
| 版本号 | AGC 不允许重复 versionCode | 每次上传前 +1 |
